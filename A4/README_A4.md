# Use case 
The program "HannahSophie08-TextGenerator.py" reads an input text file and uses it to generate new text. The user can define the order k and whether characters or words should be used for as context. A Markov Model is then built from the input, and fpr each contect the next unit is chosen randomly from all observed continuations. 

# Approach
The program uses a Markov Model of the order k. A dictionary is built from the input text, mapping each context to a list of all observed continuations. Text is generated by starting with first k units of the input, then repeatedly looking up the current context in the dictionary and randomly chosing the next continuation. The functions stops when no valid option exists for the current context or when the maximum output length is reached. 

# Input
Expected file format: text

The input file can be given as a command line argument, or via standard input.

The program can be run like this:

python HannahSophie08-TextGenerator.py [options] <input_file> 

or like this without an input file: 

echo "input_text" | python HannahSophie08-TextGenerator.py [options]

Example:
 
python HannahSophie08-TextGenerator.py -o 5 -w -f output.txt input.txt 


# Command line Parameters
- '-o k': Markov order k, must be a positive integer (default: 1)
- 'w': optional. Use word-based generation instead of character-based (default:character)
- 's': seed, optional. Seed for the random number generator, makes output reproducible
- 'n': optional. Maximum output length in characters or words. (Default: 100 000)
- f file: optional. Write output to this file instead of stdout. 
- inputfile: optional. Read rext from this file instead of stdin. 

# Output
If no output file is given with -f, the output is printed to stdout. Otherwise it is written to the specified file. In word mode, a line is limmited to approximately 70 characters for readability.

# Error handling

- If k is less than 1, the program exists with an error message 
- if k is greater or equal to the length of the input, the program exists with an error message
- all error messages are printed to stderr
