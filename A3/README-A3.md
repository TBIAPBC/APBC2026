# A3 - Manhattan

Find the best path through a grid, maximizing the sum of edge weights.


## Usage

### Synopsis

```bash
juwei95-Manhattan.py [-h] [-t] [-d] filename
```

### Positional arguments

| Argument   | Description                                 |
| ---------- | ------------------------------------------- |
| `filename` | The input file containing the edge matrices |

### Options

| Opt   | Option       | Description                  |
| ----- | ------------ | ---------------------------- |
|  `-h` | `--help`     | Show a help message and exit |
|  `-t` | `--trace`    | Print the best path          |
|  `-d` | `--diagonal` | Allow diagonal edge weights  |

### Example

```bash
python3 juwei95-Manhattan.py Manhattan-testHV1.in
```

### Tests

* Automated tests are implemented in [test-A3.sh](./test-A3.sh).

## Input

A file containing edge weight matrices.
Down and right edges are mandatory, diagonal edges are only required if `-d` is specified.

### Example

```
#G_down: 4 5
  0.60   0.65   0.91   0.94   0.14
  0.85   0.27   0.70   0.31   0.63
  0.63   0.23   0.35   0.77   0.20
  0.37   0.76   0.41   0.30   0.67
#---
#G_right: 5 4
  0.76   0.41   0.72   0.13
  0.57   0.64   0.62   0.62
  0.37   0.98   0.36   0.24
  0.99   0.77   0.39   0.35
  0.37   0.34   0.62   0.82
#---
#G_diag: 4 4
  6.74   7.03   2.47   6.25
  4.48   3.75   2.98   3.62
  7.90   3.63   3.67   3.18
  9.30   8.40   9.02   2.58
#---
```


## Output

* Prints the maximal sum of edge weights to `stdout`.
* If `-t` is given, additionally prints the chosen path through the grid.

### Example

```
58.20
EDDEDSSDDDD
```


## Details

* Performs breadth-first wavefront-propagation over a regular grid, similar to [Dijkstra's algorithm](https://en.wikipedia.org/wiki/Dijkstra%27s_algorithm).
* Found paths are reconstructed using traceback.
* Implemented in python using only standard library modules.
* Tested using python 3.12.12 on Ubuntu 24.04.3 LTS under WSL.
